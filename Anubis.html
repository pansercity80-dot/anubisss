Kenapa pilih Anubis?

Anubis dibuat untuk kamu yang capek membuka file sebuah web satu per satu. Cukup tempel link, lalu Anubis membaca halamannya dan mengambil HTML, CSS, JavaScript, gambar, font, tautan, sampai meta dan teksnya sekaligus. Semuanya dirapikan jadi file terstruktur yang bisa kamu pratinjau, salin, atau unduh sebagai ZIP maupun HTML. Tidak perlu instal aplikasi, tidak perlu daftar akun, dan tidak perlu paham kode yang rumit. Tetap hormati robots.txt dan aturan situs yang kamu scrape, lalu biarkan Anubis mengerjakan bagian yang melelahkan.

Tinggal tempel

RUNTIME

Runtime adalah mesin di balik tombol SCRAPE. Semuanya jalan langsung di browser kamu: Anubis lebih dulu memeriksa format link, lalu meminta halaman lewat endpoint /api/fetch di hosting-mu. Kalau endpoint itu tidak tersedia atau gagal, Anubis mencoba fetch langsung dan beberapa proxy cadangan sebagai jalan lain. HTML yang masuk diurai dengan DOMParser, lalu CSS dan JavaScript eksternal diambil satu per satu, ditambah gambar, font, tautan, meta, dan teks halaman. Hasilnya dikemas jadi file ZIP langsung di perangkatmu, tanpa library tambahan, dan bisa kamu pratinjau, salin, atau unduh kapan saja. Karena itu Anubis paling optimal dipasang di Vercel atau Netlify supaya jalur utamanya selalu hidup.

Pertanyaan umum

Belum yakin cara pakainya, atau bingung kenapa hasilnya tidak sesuai harapan? Di bawah ini ada jawaban untuk pertanyaan yang paling sering muncul, mulai dari apa itu Anubis, link seperti apa yang bisa dipakai, sampai alasan kenapa sebuah scrape bisa gagal dan cara mengatasinya. Ketuk salah satu pertanyaan untuk membuka jawabannya, dan ketuk lagi untuk menutupnya. Kalau kamu masih menemukan kendala yang belum terjawab, cek dulu apakah situs targetnya bisa dibuka di Chrome, lalu coba lagi beberapa saat kemudian.

Anubis adalah alat web untuk mengambil isi sebuah situs dari link-nya. Kamu tempel link, tekan SCRAPE, lalu Anubis mengumpulkan HTML, CSS, JavaScript, gambar, font, tautan, meta, dan teks halaman, kemudian mengemasnya supaya bisa dipratinjau, disalin, atau diunduh.

Tidak. Halaman ini tidak meminta akun atau login dan jalan langsung di browser. Cukup buka halamannya, masukkan link situs, lalu tekan SCRAPE.

Hanya link http atau https. Kalau kamu menulis tanpa awalan, misalnya contoh.com, Anubis menambahkan https:// otomatis. Setelah link dianggap valid, kamu akan melihat domain target yang terkunci di bawah kolom input.

Penyebab paling umum: link salah atau situsnya sedang mati, situs menolak akses otomatis dan membalas dengan kode error, atau halaman Anubis dibuka di tempat yang memblokir akses ke situs lain, seperti di dalam Claude. Pastikan situsnya bisa dibuka di Chrome, lalu coba lagi. Untuk jalur yang paling stabil, pasang Anubis di Vercel atau Netlify.

Kamu bisa mengunduh semuanya sebagai ZIP yang berisi HTML plus file CSS dan JavaScript yang berhasil diambil, atau hanya HTML-nya saja. File eksternal yang gagal diambil ditandai di dalam hasilnya. Tampilan kode di pratinjau dibatasi 80.000 karakter, tetapi ZIP berisi isi lengkapnya.

Anubis mengambil HTML yang dikirim server dan membacanya dengan DOMParser, tanpa menjalankan JavaScript halaman itu. Jadi konten yang baru muncul setelah JavaScript berjalan, seperti di beberapa aplikasi single page, bisa saja tidak ikut terambil. Di pratinjau kamu bisa menyalakan JS untuk melihat tampilannya, tetapi itu tidak mengubah isi file yang diunduh.

Tidak semua. Hormati robots.txt, syarat penggunaan situs, dan hak cipta konten yang kamu ambil. Gunakan hasil scrape hanya untuk keperluan yang memang berhak kamu lakukan. Anubis hanyalah alatnya, dan tanggung jawab pemakaiannya ada di kamu.
